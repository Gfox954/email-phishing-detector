# Email Phishing Detection Engine

A Python-based phishing detection tool that analyzes emails for malicious indicators using URL analysis, sender reputation, keyword detection, and heuristic scoring.

## Features
- URL extraction and analysis
- Suspicious TLD detection
- Keyword-based phishing scoring
- Sender reputation analysis
- Subject and body inspection
- JSON output report
- No external APIs required

## Usage
1. Place an email in `sample_email.txt`
2. Run:
   python detector.py
3. View results in `results.json`
